# Excel 365 Desktop — Ready-to-Build Installer Package

Is package me **1-Click Windows Installer Builder (`Build-Excel365-Installer.bat`)** aur **GitHub Cloud Auto-Builder** dono shamil hain.

## Option 1: Apne Windows PC par 1-Click me `.exe` banayein
1. Is ZIP ko extract karein.
2. **`Build-Excel365-Installer.bat`** file par double-click karein.
3. Process complete hote hi `dist_electron` folder khul jayega jisme **`Excel 365 Desktop Setup 1.0.0.exe`** (Installer) aur **`Excel 365 Desktop 1.0.0.exe`** (Portable) milega.

## Option 2: Bina PC par kuch install kiye GitHub se `.exe` download karein
1. In files ko apne ek naye GitHub repository me upload karein.
2. GitHub par **Actions** tab me jayein aur **"Build Windows Excel 365 Installer (.exe)"** workflow run karein.
3. 2 minute baad Artifacts section se direct compiled **`.exe` Installer** download kar lein!
